# TECHWIN — Full Android App

Offline Aviator + Crash historical/statistical analyzer.

Features:
- Average, median, min/max and standard deviation
- <1.20x, <1.50x, <2.00x, >=2x, >=5x, >=10x percentages
- Longest <2x streak
- Multiplier distribution
- Historical follow-up backtest after 1–5 consecutive <2x rounds

This is statistical analysis only. It does not hack games or guarantee the next multiplier.
